# Bekar Apply

Personal Chrome extension (Manifest V3) that auto-fills job application forms
from a locally-stored profile. Part of the Sonar monorepo — it feeds
submitted applications back to `apps/scanner/data/applications.md` and,
optionally, a Google Sheet.

**Fill-only. It never clicks submit.** Your profile lives in
`chrome.storage.local` and is never uploaded anywhere.

> Security posture: no native-messaging helper, no bundled installer, no
> Google Fonts phone-home, no background job polling. Gemini, Claude, and
> Google Sheets are opt-in and off by default.

## What it does

| Feature | Notes |
|---|---|
| Smart auto-fill | Detects fields on Workday, Greenhouse, Lever, Ashby, iCIMS + ~25 more ATS hosts and fills them from your profile |
| Cover letters | Local Ollama by default; Gemini only if you turn it on in Settings |
| Application tracker | Kanban dashboard; syncs to `applications.md` and an optional Sheets webhook |
| Learns from corrections | Reinforcement layer nudges future fills toward values you fixed |

## Build & load

```bash
cd Sonar/apps/extension
npm install
npm run build          # -> dist/
```

Then `chrome://extensions` → enable Developer mode → **Load unpacked** →
select `dist/`. After a rebuild, hit **Reload** on the card.

| Command | |
|---|---|
| `npm run build` | production build to `dist/` |
| `npm run dev` | watch mode |
| `npm test` | vitest |
| `npm run type-check` | `tsc --noEmit` |

## Profile

Import `extension-profile.json` (generated by
`packages/profile/export-extension-profile.ts` from the master profile) on the
onboarding screen. Name, email, work history, and saved answers stay in this
browser only.

## Optional local AI

Install [Ollama](https://ollama.com) from the official site only, then:

```bash
ollama serve
ollama pull llama3.2
```

The extension talks to `localhost:11434` and nothing else unless you opt into a
cloud provider.
